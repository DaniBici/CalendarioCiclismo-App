# Migraciones pendientes

Migraciones redactadas y no aplicadas en producción. Fuera de
`supabase/migrations/` para que ninguna herramienta las aplique sin decisión
expresa. Al aplicarlas con `apply_migration`, crear el archivo definitivo en
`supabase/migrations/` con la versión registrada (ver
`docs/runbooks/migraciones.md`) y eliminar el borrador de esta carpeta.
