# Notas para Stores · 5.1.3

## Español

El modo oscuro estrena paleta: fondos grafito más profundos y tarjetas con más relieve, para que perfiles, logotipos y categorías destaquen. El orden de salida muestra la cabecera de la jornada con sus documentos y un acceso directo a la etapa. Las selecciones nacionales aparecen con el nombre del país en castellano, como «Francia» o «Canadá sub23». Hoy de ciclocross se abre de una vez, con las carreras del día ya completas.

## English

Dark mode has a new palette: deeper graphite backgrounds and cards with more depth, so profiles, logos and categories stand out. The start order now shows the stage header with its documents and a shortcut to the stage. With the app in Spanish, national teams show the country name in Spanish. Cyclocross Today opens in one go, with the day's races already complete.
